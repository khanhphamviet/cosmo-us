## 3. TANAAKK — OM と X% を分離して再検討

### 3.1 なぜ「X%レンジ」だけだと危険か

契約は Net Sales×X% だが、独立企業間の中身は:

```
X% × Net Sales
  −（SORが負担する手数料・Pick/Pack・配賦オベ）
  ＝ 営業利益
  → OM% = 営業利益 / Net Sales
```

**ALの本丸は OM（または Berry）。X%は Net Sales 定義と費用負担が決まってから決まる。**

### 3.2 Net Sales 定義ゲート（Xの前提）

| 定義 | X の帰結 |
|---|---|
| **推奨:** Net Sales が **Marketplace手数料控除後**（または手数料はLCJ/配分前控除） | Xは **outbound＋米オベ＋OM** 程度 → **3–6%** が現実的 |
| Net Sales が手数料控除前で、手数料をTANAAKKのXから払う | Xは **15%級＋α** が必要 → **生地では経済破綻**。定義を変えるべきで、率で無理しない |

Category Schedule で定義を刺しゅうと突き合わせ、**生地は「手数料は配分前またはNet外」**を明確化する。

### 3.3 経済ハード制約（$5.92 / 着地≈$4.69 級）

| | $/m | 対売価 |
|---|---|---|
| 総粗利（売価−着地） | ≈1.24 | ≈21% |
| 売上15% | 0.89 | 総粗利の **≈72%** を米が先取り → **不適** |
| 売上8% | 0.47 | 総粗利の ≈38% — LCJに関税リスクバッファを残す上限付近 |
| 売上5% | 0.30 | 総粗利の ≈24% — 残余寄り |
| 売上4% | 0.24 | 総粗利の ≈19% |
| OM 2.5% | 0.15 | routineとして説明しやすい絶対額 |

出典イメージ: `fa-fabrics` の $5.93 / GP$1.24 / 15%不適。同レビューの「売価比4–7%」「<$7で5–7%」とも整合。

### 3.4 Amount B の使い方（参考に留める）

- 繊維・アパレル近傍は **Industry Group 2**。マトリクス上 ROS は因子次第でおおむね **約1.75–5%** 帯（±0.5pt等の枠あり）。  
- Path B・出荷前在庫なしは **低資産強度**寄り → **マトリクス下限〜中央**が参照として自然。  
- Amount Bは米で未実装・適用条件あり → **「正式AL」ではなくクロスチェック**。  
- よって TANAAKK の **OMオペレーティング 2.0–3.5%（中心≈2.5%）** を置く。

### 3.5 改訂 X%（契約用）

前提: **Marketplace手数料は Net Sales 外または配分前控除**（推奨定義）。

| | Net Sales × X% |
|---|---|
| オペレーティング | **3–6%** |
| 仮中心 | **≈4–5%** |
| ワイド | 3–8% |
| ハード上限 | **8%**（$6帯・現行着地前提でLCJ残余を潰し始める） |
| ハード除外 | **15%**、および「手数料控除前Net × 高X」 |

**導出（概念）:**  
`X% ≈（Pick/Pack・米配賦などのSOR費用率）+ 目標OM 2–3%`  
費用率が未計測のため中心を **4–5%** に置き、実績費用が出たら **OMが2.0–3.5%に入るようXを四半期調整**（契約に調整条項）。

### 3.6 刺しゅう15%との整合説明

| | 刺しゅう | 生地（改訂） |
|---|---|---|
| 契約型 | % of Net Sales | **同じ** |
| 率 | 15% | **3–6%（中心4–5%）** |
| 理由 | 厚いブランド余白を前提に既存合意 | 関税後GPが薄い → **同じFARでも同じ率は非AL・非経済** |

## 4. 両社を同時に置いたときのパイ制約

売価 $5.92・FSR成功・着地≈$4.7 級の **説明用**:

| 取り手 | 仮置き | 売価比イメージ |
|---|---|---|
| TANAAKK X | 4.5% | ≈$0.27 |
| 上海 ROS | 売上（対LCJ）の3% ≈ 仕入上乗せ | ≈$0.09–0.15 級 |
| 関税・補充等 | LCJ | 大きい |
| LCJ残余 | 残り | 関税・滞留バッファ必須 |

上海を4%・TANAAKKを8%に同時に振ると、LCJが構造的に赤。  
**同時適用時は上海≤3.0%かつ TANAAKK X≤5%を初期セット推奨。**
