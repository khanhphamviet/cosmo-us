# Cosmo embroidery（現行）vs quilting fabric（設計）— ownership／報酬の整合性

**Date:** 2026-09-24  
**Status:** 整合性分析（契約書未照合・数値は設計書・Excel前提）  
**Inputs:** 刺しゅう現行運用の説明（売れるまで日本ownership・売れたとき移転・net sales 85%支払）、`docs/lecien-us-quilting-fabric-business-tp-design-20260924.md`

---

## 0. 結論

| 次元 | 整合性 |
|---|---|
| **日本がprincipal／残余の経済オーナー** | **整合**（思想は同じ。生地でも日本がDEMPE＋残余） |
| **「売れるまで日本がownership」の厳格運用** | **部分整合のみ**。生地はIOR＝TANAAKK買取のため、輸入時点で米がtitleを取る設計。刺しゅう型の「顧客に売れる瞬間まで日本title」とは**形式が違う** |
| **net sales 85%（米15%）の報酬式** | **非整合・採用不可**。関税48.9%下では総粗利が薄く、同率は日本・上海を潰す。生地は**LRD＋OM目標（仮2–3.5%）**に切離し |
| **グループとしての説明可能性** | **「同一グループ方針のカテゴリ特則」**で説明可能。刺しゅう＝厚マージン代理／手数料色、生地＝薄マージン買取LRD。**同一85%式の横展開はしない** |

**一文:** 日本principalという**ownershipの思想**は揃う。ただし刺しゅうの **「売れるまで日本title＋85%送金」** を生地にそのまま当てると、**IOR・関税・利益構造の三点で破綻**する。整合させるなら「principalは日本」を共通にし、**米側の法形式と報酬式だけカテゴリ特則**にする。

## 1. 刺しゅう現行モデル（前提として整理）

ユーザー説明に基づく運用イメージ:

```
日本 ownership（売れるまで）
        │
        │  顧客に売れた時点で ownership 移転
        ▼
TANAAKK が顧客へ販売 → net sales の 85% を日本へ支払
                       （米側実質 ≈ net sales の 15%）
```

| 要素 | 刺しゅう（現行イメージ） |
|---|---|
| Principal | 日本 |
| Title | **売れるまで日本**。売れた瞬間に移転 |
| 米の法的色 | 代理／手数料色が強い（実態が買取でも契約表現は手数料寄り） |
| 米報酬 | **net sales × 15%**（日本へ85%支払） |
| 関税負担感 | 刺しゅうはブランド／小売マージンが厚く、15%が吸収可能な構造になりやすい |
| 中国LR層 | 本比較では主論点外（生地は上海Bが明示） |

## 2. 生地設計モデル（確定方針）

```
Title:    F&A → 上海(B) → 日本(principal) → TANAAKK(LRD/IOR) → Checker
Physical: Qingdao ───────────────────────────► 米（DDP）
報酬:     上海＝routine ROS／TANAAKK＝routine OM／日本＝残余
米報酬式: net sales 15% は使わない（provisional OM ≈2–3.5%）
```

| 要素 | 生地（設計） |
|---|---|
| Principal | 日本（LCJ）— デザイン・品揃え指示・DEMPE |
| Title | 上海→**日本→TANAAKK**。米は**買取LRD**としてtitle取得（IOR） |
| 「売れるまで日本」 | **顧客（Checker）売却まで日本がtitleを持ち続ける設計ではない**。日本→TANAAKKのTP2時点で米にtitleが移る（フラッシュ／短期保有は契約設計次第） |
| 米報酬 | **OM目標を満たす仕入TP**。売価比では概ね数%級の粗利幅。85/15ではない |
| 関税 | 予算48.9%。経済負担は日本へ価格調整 |

## 3. 項目別の整合性

### 3.1 ownership（思想）— 整合

| | 刺しゅう | 生地 |
|---|---|---|
| 誰が商品・利益の最終オーナーか | 日本 | 日本（残余） |
| DEMPE／品揃え | 日本想定 | **LCJ指示が明示** |
| 米は限定リスクか | Yes（手数料15%で天井） | Yes（OMレンジで天井） |

→ 「**売れるまで／利益が確定するまで、経済リスクと無形は日本**」というグループ思想は共通。

### 3.2 ownership（法形式・titleタイミング）— 部分整合／要意識的な差

| | 刺しゅう | 生地 |
|---|---|---|
| 顧客売却前のtitle | 日本 | **TANAAKKがIORとしてtitle取得する前提** |
| 日本が「売れるまでowner」と言い切れるか | 言いやすい | **厳密には言い切れない**（輸入・通関時点で米title） |
| フラッシュtitle（売却直前にのみ米へ） | 刺しゅう型に近い | 理屈上は可能だが、**IOR・危険負担・支払が日本に残っていないと否認・形式実態不一致リスク** |

**重要:** 生地で「刺しゅうと同じく売れるまで日本ownership」を**文言だけ**維持し、実態はTANAAKKがIOR・買取・与信を取る、は**最悪のパターン**（形式＝手数料／実態＝distributor）。生地は**買取LRDと明示**し、ownershipストーリーは「**日本がグループprincipalで残余を取る**」に言い換えるのが安全。

### 3.3 報酬式（85% / 15%）— 非整合

| 売価 $5.92、着地後GPが薄い前提 | 刺しゅう同率15% | 生地設計（OM≈2.5%） |
|---|---|---|
| 米取り分の性格 | 売上連動・厚い | 営業利益連動・薄い |
| 関税48.9%後の残余 | 15%が総粗利の大半を食う（既存レビューどおり） | 日本が残余を確保できる余地を残す |
| 契約 | 既存代理／85%支払 | **生地特則で切離し必須** |

→ **同じ「日本ownership」でも、送金式を85%に揃える必要はない。揃えると経済が壊れる。**

### 3.4 上海レイヤ — 刺しゅうに無い（または薄い）追加

生地は **上海＝B型LR（LCJ指示の発注窓口）** が挟まる。  
刺しゅうの「日本↔米の85%」二項関係より一段多い。整合性の論点は主に**米エンド**であり、上海は生地固有のFAR追加。

## 4. 「整合させる」ための実務オプション

| オプション | 内容 | 評価 |
|---|---|---|
| **A. 推奨（現行設計）** | 思想は日本principalで共通。米は生地特則＝**買取LRD＋OM**。85%式は刺しゅう専用 | **採用。** 説明は「カテゴリ特則」 |
| **B. 形式も刺しゅうに寄せる** | 生地も「売れるまで日本title＋85%送金」 | **関税・IORと衝突。非推奨** |
| **C. 経済だけ寄せる** | titleはLRDだが、送金を「net salesのX%」に見せる | Xを2–5%級に落とさない限り不可。見せ方はcommission色が残り税関加算リスク |
| **D. 刺しゅうを生地に寄せる** | 将来、刺しゅうもOM型LRDへ | 別プロジェクト。今回の必須ではない |

**対外・対内の言い方（推奨）**

- **共通:** 「米国事業のprincipalは日本。米は限定リスク。」  
- **差分:** 「刺しゅうは既存の net sales 連動報酬。quilting fabric は関税構造が異なるため買取LRD＋営業利益目標で報酬を設定する。」  
- **避ける:** 「生地も刺しゅうと同じく売れるまで日本所有・85%送金」

## 5. 批判的チェック

1. 刺しゅう実態がすでにIOR買取なのに契約だけ85%なら、**刺しゅう側にも形式／実態ギャップ**がある可能性 — 生地で同じギャップを増やさない。  
2. 「ownershipは売れるまで日本」をグループ口癖にすると、生地の直送＋米IORと広報が矛盾する — **口癖を「principalは日本」に更新**した方がよい。  
3. 85%を「日本への仕入代金」と会計しているなら、生地のTP2買取と勘定科目は揃えやすい。85%を「売上送金」としているなら、生地は仕入／売上の買取仕訳に切替が必要。

---

## 6. 一文サマリー

**日本principalという意味でのownership思想は刺しゅうと整合する。しかし「売れるまで日本title＋net sales 85%」は生地ではIOR・関税・利益の三点で踏襲できない。整合の正しい取り方は、principal＝日本を共通にし、米報酬だけ生地特則（LRD／OM）に分離すること。**
