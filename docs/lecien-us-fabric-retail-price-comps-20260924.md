## 3. LECIEN $14.4/yd の読み方

```
LECIEN 含意小売 ≈ $14.4/yd
         │
         ├─ vs 量産ソリッド ($8–9.5)     → 大幅に高い（プリント故に妥当な差）
         ├─ vs アジア産ミッドハイ ($11–13.5) → やや高い〜上端（約 +$1–3）
         ├─ vs 米デザイナー ($12–14.5)   → ほぼ同帯（Ruby Star/Riley Blakeと並ぶ）
         ├─ vs Sevenberry流通 ($11.5–13) → やや高い
         ├─ vs Kokka Made in Japan ($19–23) → 明確に安い（Japan originプレミアムは取れない）
         └─ vs Liberty (~$40)           → 別カテゴリ
```

### 価格設定上の結論
1. **比較に China high tier（＝米小売のアジア産ミッドハイ帯）を入れるのは必須。** LECIENはそこと **同帯〜わずかに上**。  
2. **日本産明示（Kokka Britex帯）を主ベンチにしない。** COOが中国のため、そのプレミアムは説明できない。  
3. **品質「日本同等」はストーリー、価格は「米デザイナー下〜中／アジア上位」** が整合。  
4. $14.4がきつい場合の調整レバー: 下代を$5.6–5.8へ寄せる、または小売想定を$13台（流通マージン圧縮）に落とす説明。

## 4. 批判的注意
- 「China high tier」の店頭ラベルは稀。**価格帯ピア**として Henry Glass / Clothworks / Wilmington / Timeless を使うのが実務的。  
- Wilmington等は **Korea** 表示SKUあり → 「全部China」ではないが、**非Japan・非米デザイン頂点**の競合として有効。  
- Sevenberryは日本イメージだがFQS **$11.48** もあり、LECIEN $14.4は「日本名」だけでは正当化不足。  
- Checker他社仕入 $5.62/m（<$5.92）は、小売換算でもLECIENがやや高い側に残る。
