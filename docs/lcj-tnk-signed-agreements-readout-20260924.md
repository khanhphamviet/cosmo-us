# LCJ–TANAAKK 署名済み契約の読解 — 刺しゅう「固定方針」の実体と生地寄せ

**Date:** 2026-09-24  
**Status:** 契約読解メモ（法的助言ではない）  
**Sources (署名済み PDF):**

## 0. 結論（先に）

署名済みの Cosmo／LECIEN×TANAAKK モデルは、先日の説明・添付表で使っていた **「LCJ→retailer／TANAAKK ownershipなしのまま売却」ではない。**

**実体は契約タイトルどおり `Consignment + U.S. Principal`:**

| 層 | 契約上の決め |
|---|---|
| 米顧客への売主（SOR） | **TANAAKK**（Principal）。LECIENは顧客に対する Agent ではない |
| 3PL到着〜出荷前の在庫owner | **LECIEN**（consignment） |
| Title移転 | **3PL出荷日**（または直送では国際運送人への tender 時）に LECIEN→TANAAKK |
| Title移転の性格（Path B） | **通常の関連会社間売買・仕入を構成しない**（consignment履行に伴う移転） |
| 精算 | Net Sales の **15% = TANAAKK／85% = LECIEN** |
| IOR | **TANAAKK**（関税等は立替→LECIEN実費精算） |
| 3PL契約主体 | **TANAAKK**（保管料等は LECIEN へ pass-through） |

したがって「刺しゅう方針固定」＝ **この署名済みシェルを動かさない**、と読むのが正しい。  
生地を近づける＝ **同じ Master の Product／Channel スケジュールで生地を載せる**（Shanghai・China原点・関税・必要なら報酬率だけ付則）。  
先日の「LCJがFaire売却の売主」表は、**契約と矛盾する簡略化**なので寄せ先にしない。

## 1. 原契約の要点

### 1.1 目的・役割（Art.1–2）

- TANAAKK = **Seller of Record**（顧客契約、受注、返金、価格・プロモ最終決定、Amazon/Faire/Shopify、**IOR**、広告、CS、3PL出荷確定、返品）  
- LECIEN = 供給・**出荷日前までの consignment 在庫所有**、製造・QA、補充、ブランド資産  
- LECIENは商品情報の編集アップロード可。価格・広告・返金・出荷確定は TANAAKK 限定  

### 1.2 報酬（Art.3）

| 取引 | 精算 |
|---|---|
| 米国販売（3PL等、SOR=TANAAKK） | **TANAAKK 15% / LECIEN 85%** of Net Sales |
| Super Delivery（日本B2B直販、SOR=LECIEN） | TANAAKK が Net Sales 15%を**コンサル成果報酬**（米SOR取引とは別） |

Net Sales ≈ Gross − Returns −（定義どおりの控除）。True-upあり。

### 1.3 費用（Art.4）

| 費用 | 最終負担 |
|---|---|
| 日本→米3PLの国際輸送・通関・入庫・保管 | **LECIEN**（在庫owner） |
| 関税・broker・bond等 | TANAAKK立替 → **LECIEN実費** |
| 3PL Pick/Pack/Outbound、Marketplace手数料 | **TANAAKK**（SOR） |
| 3PL契約名義 | TANAAKK |

### 1.4 Title（Art.5）

- **3PL ship date** に LECIEN → TANAAKK  
- 出荷日前の在庫リスク = LECIEN  
- 品質不良返品 = LECIEN；顧客都合返品は市場浸透として LECIEN が一部/全部負担し得る

## 2. Amendment No.1（SNS）

- 原契約の **SOR=TANAAKK** を維持  
- SNS・ブランドIPの所有は LECIEN  
- 米向け商業コミュニケーションの権限分界（詳細は本メモの主論点外）  

→ 生地寄せの所有／精算モデルは変えない。

## 3. Amendment No.2（Direct Shipment）

### 3.1 何を直したか

- 日本→米顧客直送（Distributor／Faire、Display Cabinet、backorder等）の精算・Title・危険負担  
- **モデルは変えない:** SOR=TANAAKK、Consignment + U.S. Principal、**Path B**  
- 暫定の「送料・関税を入れない基礎の85%払い」を改め、**Direct Fulfillment Costs を 15%/85% 配分前に控除**、LECIEN立替実費は Settlement 返還  

### 3.2 Title（直送）

- LECIEN → TANAAKK：国際運送人への tender 時（Shipment Instruction に基づく）  
- 性格は 3PL出荷日と同じ **Path B（通常の売買仕入ではない）**  

### 3.3 対象外（重要）

- 日本→米3PL**補充**の国際送料・関税 → 原契約の在庫owner／pass-through  
- Super Delivery（SOR=LECIEN）  
- 米国内3PL outbound → 既存 Net Sales ルール

## 4. 口頭・添付表とのズレ（補正）

| 先日の簡略イメージ | 署名済み契約 |
|---|---|
| 売れるまで日本ownership、売れたら顧客へ | **出荷日まで** LECIEN ownership。顧客への売主は **TANAAKK（SOR）**。出荷日に LECIEN→TANAAKK（Path B） |
| TANAAKK ownership なし（全段階） | 出荷前はなし。**出荷日以降は TANAAKK に title**（ただし Path B＝通常仕入ではない） |
| Faire売却 = LCJ → retailer | **SOR=TANAAKK → retailer**。精算で85%を LECIEN へ |
| 添付「Principal = LCJ」 | ブランド／在庫ownerの意味では近いが、**米商業 Principal / SOR は TANAAKK**。契約名も U.S. Principal = TANAAKK 側 |

「85%を日本へ払う」は契約と一致。  
「LCJが米顧客の売主」は契約と**不一致**。

## 5. 生地を「刺しゅう固定」に近づける含意

刺しゅう固定 = **この Master を動かさない**。

| 寄せ方 | 内容 | 評価 |
|---|---|---|
| **推奨** | 原契約の適用 Product に quilting fabric を追加（または Category Schedule／Amendment No.3）。シェルは同一: Consignment + U.S. Principal、Path B、SOR/IOR=TANAAKK、出荷日 title、Net Sales 配分 | 契約・オペ・説明が一本 |
| 報酬 | 型は 15%/85% と同じ。**生地は率だけ別スケジュール（X%/ (100−X)%）** — 関税後経済が壊れないよう X≪15 | 必須 |
| 物流付則 | China→U.S.（直送／3PL）。補充の関税・国際送料は **在庫owner=LECIEN 負担**（原契約 Art.4と同型） | 刺しゅうの Japan→U.S. と物理だけ違う |
| 上海 | Master の外または別紙: F&A→上海 $2.95、上海→LCJ。米レグは既存シェル | 刺しゅうに無い層 |
| やってはいけない | 生地だけ「LCJ→顧客売主」や「TANAAKK買取LRD＋OM」にすると、刺しゅう固定シェルからまた分岐 | 寄せ失敗 |
| Path B×FSR | 米Entryは IOR=TANAAKK。第一売買候補は F&A→上海。Path Bは「日↔米が通常仕入でない」旨。Brokerに **consignment + Path B + FSR** の両立を確認 | Go条件 |

---

## 6. 批判的メモ

1. 契約はすでに「在庫はLECIEN、売主はTANAAKK、titleは出荷瞬間」と**巧みに分離**している。添付表より正確で、先日のLRD案とも「出荷前owner」は近いが、**精算がOMではなく15%Net Sales**な点が生地で痛い。  
2. Path B（売買にしない title 移転）は税務・会計・税関で説明負荷がある。生地高関税で同じ型を増やすなら、Broker／税理士に **quilting追加の影響**を明示質問すべき。  
3. Amendment No.2 が直送の送料・関税を配分前控除にしたのは、生地 China直送でも**同じ思想で付則を書ける**先例になる。  
4. Super Delivery の15%は別取引。生地を Faire/3PL/Distributor に載せる話と混線させない。

## 7. 一文サマリー

**署名済みの刺しゅう方針は「Consignment + U.S. Principal」：出荷前在庫=LECIEN、米売主・IOR=TANAAKK、出荷日にPath Bでtitle移転、Net Sales 15/85。生地を近づけるならこのシェルに載せるのが正解で、先日の「LCJ→retailer」表は寄せ先にしない。変えてよいのは主に上海層・China物流と生地の報酬率X%だけ。**
