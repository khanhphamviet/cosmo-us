# First Sale $2.95 が通らなかった場合 — 影響と可能性

**Date:** 2026-09-24  
**前提:** D=$6.17/m（小売$15/yd）、関税率48.9%は維持、変わるのは**課税価格（customs value）**  
**Status:** 感度メモ（Broker意見ではない）

---

## 0. 結論

| 問い | 答え |
|---|---|
| 通らなかったら何が起きるか | 米Entryの建値が **$2.95より高い関連者価格**に上がり、**関税額が比例増**。輸入後の原資23.8%が縮小し、**削られるのは主にLCJ残余**（上海・TANAAKKのroutineは契約で守る） |
| 可能性 | **「あり得るが、運用次第でかなり下げられる」中リスク。** ゼロにはできない。雑な全世界在庫型よりは強いが、Path B＋多段関連者のため**否認・修正の余地は残る** |

---

## 1. 通らなかったときに起きること

### 1.1 法・通関上

1. CBP/Brokerが First Sale（F&A→上海 $2.95）を認めない。  
2. 課税価格が次のいずれかへ（設計・交渉次第）:  
   - **上海→LCJ** の関連者価格（≈$3.0x）  
   - より高い関連者建値・再構築価格  
   - 最悪に近い議論では米販売近傍まで持ち上げられる主張もあり得る（実務はケース次第）  
3. 関税率48.9%は**原産地が中国のままなら基本そのまま**（FSRは税率ではなく**税額のベース**の話）。  
4. 追徴・利息・将来Entryの是正の可能性。

### 1.2 お金（D=$6.17固定・物流額据え置き仮）

| シナリオ | 課税価格 | 着地概算 | 輸入後原資（対D） | LCJ残余イメージ※ |
|---|---:|---:|---:|---:|
| **Base（FSR成功）** | **$2.95** | **$4.69** | **$1.48（24%）** | **≈$1.05（17%）** |
| 軽い否認（上海売価級） | ≈$3.04 | ≈$4.73 | $1.44（23%） | ≈$1.02（17%） |
| 中程度 | ≈$3.50 | ≈$4.96 | $1.21（20%） | ≈$0.80（13%） |
| 重い（旧中間TP級） | ≈$3.86 | ≈$5.13 | $1.04（17%） | ≈$0.62（10%） |
| かなり重い | ≈$5.04 | ≈$5.71 | $0.46（7%） | ≈$0（1%未満） |

※上海利益≈$0.08＋TANAAKK OPEX+OP≈$0.34を原資から差引いたイメージ。

**追加関税の大きさ（対Base、$2.95比）**

| 課税価格 | 追加関税 $/m | 概算 /FCL（35,000m） |
|---:|---:|---:|
| $3.04 | +$0.04 | ≈+$1.5k |
| $3.86 | +$0.44 | ≈+$16k |
| $5.04 | +$1.02 | ≈+$36k |

以前のExcel感度「約$9.8k/FCL」は、建値の上げ幅が中程度のケースに相当するオーダー。

### 1.3 誰が痛むか

| 当事者 | 影響 |
|---|---|
| **LCJ** | **主負担。** 在庫owner・残余。原資23.8%が減る分はここが吸う |
| 上海 | routine維持が原則（売価調整でROS確保）。パイ全体は減る |
| TANAAKK | 契約上 OM/X を守るなら、**率は維持・LCJ払いが増える／売価改定** |
| 顧客売価 | 短期は契約どおり。中期は **Dや小売の引き上げ・SKU縮小**が必要になり得る |

## 2. 可能性はどの程度か

**数値の「○%の確率」は出せない**（Broker・実績Entryがないため）。代わりに条件付き評価:

### 2.1 このスキームで FSR が相対的に強い点

| 要因 | 評価 |
|---|---|
| F&A↔上海が**非関連**、$2.95が実態価格 | 第一売買の候補として強い |
| **完全受注生産・米向け分離**が可能 | clearly destined を作りやすい |
| 日本倉庫・グローバル引当をしない | 弱い型を避けている |
| Mode A/Bとも US向けPOを分けられる | 証憑設計と整合 |

→ 「最初から無理」な構造ではない。**ちゃんと運用すれば通る余地は十分ある。**

### 2.2 否認・争いが残りやすい点

| 要因 | 評価 |
|---|---|
| 上海→LCJ→（Path B）TANAAKK の**多段・関連者** | 税関の目が厳しくなりやすい |
| Path B（通常仕入でない title）＋ IOR=TANAAKK | Entry説明が複雑 → **誤解・否認の呼び水** |
| 3PLに LCJ consignment 長期在庫 | 「米向け確定」証憑が弱いと攻撃材料 |
| Design assist・関連者役務の加算漏れ | 建値修正の典型 |
| 書類不整合（PO・インボイス・荷印） | **運用失敗時は否認確率が大きく上がる** |

### 2.3 実務的な見立て（定性）

| 状態 | 見込み |
|---|---|
| Broker手続＋米向け分離PO＋証憑5年が揃う | **通る見込みは相応にある（ベースケースに置ける）** が、**保証はできない** |
| 証憑が弱い／転用あり／Path B説明不足 | **否認・修正は十分現実的（ダウンサイド必須）** |
| 業界感 | First Saleは条件付き救済で、**監査・CF-28で争点化しやすい**領域。確率ゼロ想定は不適切 |

**経営用の置き方:**  
- **Base予算 = FSR成功（$2.95）**  
- **必須感度 = 少なくとも課税価格 +$0.5〜1.0/m（原資が20%→17%前後、またはそれ以下）**  
- **意思決定:** FSRを「節約前提の確定」ではなく **アップサイド**、否認を **標準リスク**として価格・契約に織り込む。

---

## 3. 否認時のオペ対応（短）

1. Entryを関連者建値で確定／修正。  
2. 追加関税は **LCJ負担**（契約明記済みであるべき）。  
3. 四半期で D または X/費用を見直し（調整条項）。  
4. 再発防止: PO・仕向地・assistのゲート強化。  
5. 連続否認なら FSR前提の売価をやめ、**建値高め前提で D を上げる**かSKU縮小。

---

## 4. 一文サマリー

**$2.95 FSRが落ちると税率は同じでも税額が上がり、23.8%原資が縮んでLCJ残余が先に削られる。可能性は「運用が良ければ通るが、多段関連者＋Path Bのため否認は無視できない中リスク」。予算は成功ベース、感度は必須。**
