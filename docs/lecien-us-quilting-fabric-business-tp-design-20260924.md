- **上海→日本倉庫→米国**の物理ルート（LT・コスト・FSRとも直送に劣る）

- 上海＝A（agentのみ）— TeamsでB採用済みと矛盾

## 2. 推奨ビジネスモデル

### 2.1 役割分担（FAR）

| 会社 | 法的役割 | 主機能 | 主リスク | 主資産 |
|---|---|---|---|---|
| **F&A** | 第三者メーカー | **完全受注生産**のプリント製造。米向けロット分離可 | 製造 | — |
| **上海ルシアン** | Limited-risk buy-sell | **LCJ指示のデザイン・品揃えをF&Aへ発注**。購買・検品・中国輸出・米向けPO実務 | 短期運転資本・製造遅延の一次対応（最終は日本へ転嫁） | 運転資本（短期） |
| **日本ルシアン（LCJ）** | Principal / IP owner | **デザイン・品揃えの指示**・価格政策・仕入承認・品質基準・global需要 | 市場・滞留キャンセル・関税・FSR否認・為替（円）・PL最終 | 無形資産（DEMPE） |
| **TANAAKK** | LRD + IOR | 米営業・与信・通関・関税納付・顧客対応 | 与信（Checker）、申告手続 | 顧客関係（米） |

**指揮系統（デザイン／品揃え）**

```
LCJ（日本） ──指示──► 上海 ──発注──► F&A（受注生産・米向け分離）
```

上海は企画の意思決定者ではない。意思決定とDEMPEは日本に残す。

### 2.2 商流（title）と物流（physical）の分離

```
Title:   F&A ──$2.95──► 上海 ──TP1──► 日本 ──TP2──► TANAAKK ──$5.92──► Checker
Physical: Qingdao ──────────────────────────────────────────► 米拠点（DDP）
Documents: TANAAKK米向けPO → 日本承認 → 上海→F&A米向けPO → 船積・荷印US指定
```

**物流判断（確定）**

| ルート | 評価 |
|---|---|
| **Qingdao（上海経由実務）→ 米国** | **採用。** LT4w・コスト・FSR（米向け荷印貫通）に適合 |
| 上海 → 日本倉庫 → 米国 | **不採用。** 二重物流・倉庫コスト・LT悪化。全世界引当になるとFSRも弱体化 |

**ポイント**
- 日本に**実倉庫を置かない**（FSR・コスト・LT）。titleと請求だけ日本を通す。  
- 上海は back-to-back（F&A完全受注生産）。長期在庫なし。  
- TANAAKKがIOR。関税・MPF/HMFの**経済負担は日本へ価格調整**（契約明記）。

### 2.3 契約パッケージ（必須）

| 契約 | 当事者 | 要点 |
|---|---|---|
| 購買契約 | 上海–F&A | 完全受注生産、title/危険負担移転時点、品質、**US向けPO・ロット分離**条項 |
| 限定リスク再販 | 上海–日本 | back-to-back、**デザイン／品揃えはLCJ指示**、滞留・キャンセル・最終品質は日本、上海はroutine margin |
| 販売／LRD | 日本–TANAAKK | buy-sell、報酬＝OM目標を満たすTP、四半期価格調整、関税・FSR変動の転嫁、IOR明記 |
| IP／デザイン | 日本（単独または上海・米への許諾） | DEMPEの所在、assist提供の記録、上海は実施窓口 |
| 生地特則 | 既存米代理15%契約へのamend | **quilting fabricは15%対象外**／LRD買取に切替 |

### 2.4 First Saleオペレーション（必須ゲート）

前提: **F&A完全受注生産**により、米向け数量・仕様・荷印を他市場と物理分離できる。

1. Checker（等）需要確定 → TANAAKKが**米向け数量PO**を日本／上海へ。  
2. **LCJがデザイン・品揃え・数量を承認／指示** → 上海がF&Aへ**同一数量・US destination・固有PO番号**で発注。  
3. 製造・梱包・船積書類にUS指定が貫通（LT目安**4週**）。  
4. EntryでFirst Sale申告。証憑5年保管（輸入者＝TANAAKK）。  
5. Design assistは該当時のみ加算（現Excel $0.06はprovisional）。

**失敗時のfallback:** customs value = 関連者建値（日本→TANAAKKまたは上海→TANAAKK）。Excel感度どおり **約$9.8k/FCL級の打撃**を日本が吸収する前提で予算化する。

## 3. 移転価格設計

### 3.1 方法論（順序を固定）

```
① FAR確定（契約＋実態）— 日本principal／上海＝LCJ指示の発注窓口
② 検証対象：上海・TANAAKKを tested party（routine）
③ TNMM等で arm’s-length ROS / OM レンジを取得
④ そのレンジ中央寄りを達成するよう TP1・TP2 を逆算
⑤ 残余＝日本（DEMPE）
⑥ 文書化（日・中・米）
```

**禁止する説明:** 「グループ利益の10%だから上海ROS 2.9%」「先に米5%ありき」を最終文書の主根拠にすること。  
**暫定オペ:** 09-28までは **provisional targets**（下記）で走らせ、90日以内にbenchmarkで置換する、と明記する。

### 3.2 Provisional targets（Excel P1を「仮の操作目標」に再定義）

| tested party | 指標 | Provisional目標 | 根拠の扱い |
|---|---|---|---|
| 上海 | 対売上 ROS | **2.5–4.0%**（仮中心 **≈2.9%**） | 中国6号公告の「合理的利益」方向・調達上乗せ3–10%の参考。**要DBベンチマーク** |
| TANAAKK | 対売上 OM | **2.0–3.5%**（仮中心 **≈2.5%**） | Amount B繊維参考1.75–5%は参考値（経費率条件に注意）。**要ベンチマーク** |
| 日本 | 残余 | 残り全部 | DEMPE証跡が条件（デザイン・品揃えの指示主体） |

売価定着 **$5.92**、FSR成功、関税48.9%、FCL前提なら、現行Excelの  
`TP1≈$3.10` / `TP2≈$3.86` は **暫定キャリブレーションとして利用可**。  
LCLや関税否認時は **TP2を下げず、日本残余が減る**（価格調整条項）。

### 3.3 価格の決め方（実務アルゴリズム）

**四半期ごと（またはFCLごと）:**

1. 確定: 米売価、実効関税率、物流（直送）、FSR成否、assist。  
2. TANAAKK: 目標OMを満たすよう **仕入TP2** を設定  
   `TP2 ≈ 売価 − 関税等 − 物流 − 米経費 − 目標OM×売価`  
3. 上海: 目標ROSを満たすよう **TP1** を設定  
   `TP1 ≈ (F&A原価 + 上海経費) / (1 − 目標ROS)`  
4. 日本: `TP2 − TP1 − 日経費` が残余。マイナスなら売価改定または数量見直し。

関税1pt・FSR否認は **日本吸収**（上海・米のroutineは契約上保護）。

### 3.4 刺しゅう15%との関係

| | 刺しゅう（現行イメージ） | 本quilting fabric（本設計） |
|---|---|---|
| 米の形態 | 手数料／代理色が強い | **買取LRD** |
| 報酬 | 売上≈15% | **OM≈2–3.5%**（売価比では概ね4–6%級の粗利幅に相当し得るが、関税込みでは15%不可） |
| 契約 | 既存 | **生地特則で明示切離し** |

「commissionモデルを維持したい」場合でも、実態が買取・IOR・与信なら **性格付けはLRD**に合わせる（アドビ事件型の形式・実態不一致を避ける）。名目だけcommissionは関税加算・TP両方で危険。

### 3.5 日本ownershipは崩れるか

| 問い | 本設計の答え |
|---|---|
| 日本が商品titleのprincipalか | **Yes**（上海→日本→TANAAKK）。確定方針 |
| 日本倉庫が必要か | **No**（上海→米直送の方が妥当） |
| 上海＝Bと矛盾するか | **しない**（上海はF&Aからのbuyer、日本へのseller。企画はLCJ指示） |
| 上海→TANAAKK直販にする場合 | 日本ownershipは商品上崩れ、**ロイヤルティ／役務**へ切替（代替案） |

## 8. 批判的自己チェック

1. **titleに日本を残す**のはownership・残余のため。FSRと物流だけなら上海→米の方が単純 — 組織優先（日本principal）で複雑性を受け入れている。  
2. Provisional 2.9%／2.5%はExcel依存。benchmarkで外れたらTPを動かす覚悟が必要。  
3. 「直送なのに日本がbuyer」はフラッシュタイトル否認リスク — **危険負担・保険・支払・キャンセル負担**を日本に実質残すこと。  
4. 48.9%未確定のまま$5.92を市場に出すと、税率が下がれば余剰、上がる／FSR否認なら日本が全て食う。  
5. Checker $5.62競合に対し$5.92は品質・デザイン訴求が必要（中国産であることの説明含む）。  
6. 上海のFARを「企画」と書きすぎるとDEMPEが上海に寄る — **LCJ指示の発注窓口**に実態・契約を揃えること。
