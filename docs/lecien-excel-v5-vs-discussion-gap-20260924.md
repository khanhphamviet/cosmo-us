## 2. 不一致・要すり合わせ

### 2.1 【最大】米レグの契約モデル

| | Excel P1 | これまでの議論（寄せ後） |

| 性格付け | **buy-sell LRD** | 署名済みに合わせ **Consignment + U.S. Principal / Path B** |
| 日→米 | **仕入TP ≈$3.86/m**（FOB換算） | **通常の仕入売買にしない**（出荷日にtitle、精算は% of Net Sales） |
| 在庫 | 米在庫なし・Maumee直送 | **Faire用は米3PLにLCJ consignment**、backorderはCN直送 |
| 既存契約 | 「15%代理→生地はbuy-sell・5%特則」と書く | 刺しゅう固定＝**既にConsignment+SOR**。生地も同シェル＋X% |

**含意:** Excelは「新しいLRD買取モデル」前提。議論の到達点は「**既存Masterに載せる**」。ここが揃わないと契約・会計・税関説明が二重になる。

### 2.3 TANAAKK報酬の「型」と率

| | Excel | 議論 |

## 4. すり合わせ提案（実務）

1. **契約:** Excelの「生地はLRD買取」をやめ、**既存 Consignment+SOR に Category Schedule**（議論どおり）。Excelの$3.86は **精算シミュレーション用の換算**に格下げするか廃止。  
2. **TP文書:** 上海は **ROSレンジ**で書く。グループ10%シェアは内部KPIに留める。  
3. **TANAAKK:** 「5%」を残すなら **OPEX後OM≈2.5–3%になる率**と定義し、Net Sales定義をMasterと一致させる。  
4. **Excel改訂:** Faire 3PL・backorder・売価$6.17／小売$15のケースをタブ追加。  
5. **一致を活かす:** F&A $2.95、48.9%、FSR、日principal、両端routine・日残余、15%不使用、否認~$9.8k — この骨格は共通メッセージにしてよい。
