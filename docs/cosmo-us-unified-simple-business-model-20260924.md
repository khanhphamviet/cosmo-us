# COSMO US 統一シンプル・ビジネスモデル（刺しゅう＋quilting）

**Date:** 2026-09-24  
**Status:** 統合設計案（契約書化・benchmark・刺しゅう移行計画前）  
**Goal:** Cosmo embroidery と Lecien quilting fabric を、**できるだけ同じ言葉・同じ契約骨格**で回す  
**Inputs:** 生地TP設計、Faire/3PLチャネル、刺しゅう85%整合性分析

---

## 0. 結論（推奨の単純形）

**モデル名: One Principal / One US LRD**

| ルール | 内容 |
|---|---|
| 1 | **日本が唯一の principal**（DEMPE・品揃え・価格政策・残余利益） |
| 2 | **TANAAKKは常に buy-sell LRD ＋ IOR**（全カテゴリ・全チャネル） |
| 3 | **米報酬は「売上%」ではなく routine OM**（TNMM）。刺しゅうの net sales 85%／15%は廃止方向 |
| 4 | **「売れるまで日本がtitle」はやめる**。輸入時点で米がtitle。日本は**経済リスク**を契約で吸収 |
| 5 | **チャネル差は物流だけ**（直送 vs 3PL）。契約・FAR・報酬の型は変えない |
| 6 | **中国法人は「必要なときだけ」LR買取**（生地の上海B）。刺しゅうで中国買取が無いなら層を増やさない |

```
共通骨格:
  [中国メーカー] → (必要なら中国LR) → 日本 principal → TANAAKK LRD/IOR → 顧客
物理のみ分岐:
  D: メーカー／港 → 顧客直送
  F: メーカー／港 → 米3PL → Faire/出荷
```

**捨てるもの（複雑さの主因）**

- カテゴリごとに「手数料」と「買取」が混在すること  
- 「売れるまで日本ownership」という口癖（IOR実態と矛盾）  
- 生地だけ特則、刺しゅうだけ85%、Faireだけ別性格付け  
- 日本倉庫を関税・FSRのために挟むこと  

---

## 1. なぜこれが「simple」か

| 今（実質） | 統一後 |
|---|---|
| 刺しゅう＝85%送金＋ownership口癖 | 刺しゅう＝LRD買取＋OM |
| 生地＝LRD＋OM（設計） | 生地＝同じ |
| Faire＝物理は3PL、言い方は刺しゅう寄り | Faire＝同じLRD＋3PLtitleは米 |
| 説明がカテゴリで分岐 | **説明は1枚**。違うのは原価・関税・OMの数値だけ |

オペ（Faire、ShipHero、問屋直送）は今のままでよい。  
変えるのは **契約の性格付けと送金式** が中心。

---

## 2. 役割（FAR）— 全SKU共通

| 会社 | 役割 | 全カテゴリで同じか |
|---|---|---|
| **日本（LCJ / Cosmo本体側）** | Principal | Yes |
| **TANAAKK** | LRD + IOR + 米営業・与信・3PL管理 | Yes |
| **上海ルシアン** | 中国 sourcing の LR buy-sell（発注窓口） | **生地など中国買取があるときだけ** |
| **第三者メーカー**（F&A等） | 製造 | カテゴリごと |
| **3PL** | bailee（保管・出荷）。titleなし | Faire等で使用時 |

指揮系統（共通）:

```
日本 ──品揃え・価格・補充指示──► （上海があれば上海）──発注──► メーカー
日本 ──TP売価──► TANAAKK ──► 顧客 / Faire
```

---

## 3. Title・リスク・お金（1ルール）

### 3.1 Title

| 時点 | 誰がtitle |
|---|---|
| メーカー出荷〜（中国LR経由時） | 契約どおり上海→日本へ |
| **米輸入・3PL入庫** | **TANAAKK** |
| 顧客／Faire小売へ販売 | TANAAKK → 顧客 |

日本は「倉庫の名義owner」ではなく **principal（指示・残余・リスク吸収）**。

### 3.2 リスク配分（単純）

| リスク | 負担 |
|---|---|
| 市場・滞留・評価減・返品 | **日本**（buyback／価格調整） |
| 関税・FSR成否の経済 | **日本** |
| 与信（顧客） | TANAAKKが一次、重大不良は日本へ転嫁可 |
| 米routine利益 | TANAAKKが **OMレンジ内**で確保 |

### 3.3 報酬（単純）

```
① 米売価・実費（関税・運賃・3PL・Faire手数料・返品見込）を確定
② TANAAKK が目標OMに載るよう 仕入TP（日本→米）を決める
③ 中国LRがあれば、そこの routine ROS を満たす中間TP
④ 残り全部 = 日本の残余
```

| カテゴリ | OMの扱い | 売上15% |
|---|---|---|
| Quilting | provisional 2–3.5% → benchmark | **禁止** |
| Embroidery | **移行後は同じOM枠**（暫定は現行経済に近いTPでも可） | **廃止方向** |

刺しゅうで「今の米P&Lを急に薄くしたくない」場合でも、**式はOM／仕入TPに統一**し、最初の数四半期だけOM目標を高めに置く（例: 歴史的15%粗利相当をOMに換算）。**式を85%のまま残すのはsimpleに反する。**

## 4. チャネルは2つだけ（物流差）

| ID | 名前 | 物理 | 在庫 | 向くもの |
|---|---|---|---|---|
| **D** | Direct | 港→顧客 | なし | 大口Distributor、受注生産生地 |
| **F** | Fulfillment | 港→米3PL→出荷 | あり | Faire、小口、刺しゅう既存 |

契約は共通。Channel Fだけ付則: 在庫buyback、3PL費用、補充PO。

---

## 5. カテゴリ差分は「数値と中国層」だけ

| | Cosmo embroidery | Lecien quilting |
|---|---|---|
| 骨格 | One Principal / One US LRD | 同じ |
| 中国LR | 現行に無ければ **置かない** | 上海B（LCJ指示の発注） |
| First Sale | 該当すれば同じ規律 | F&A $2.95・米向け分離 |
| 関税 | 現行HTS | 予算48.9%感度 |
| 売価 | 既存 | $5.92帯など |
| OM | 統一フレームワーク | 同じ（数値は別にキャリブレーション） |

**「生地特則」「刺しゅう特則」という別モデルは作らない。**  
作るのは **Category schedule（原価・関税・OM・有無の中国層）** 一枚。

---

## 6. 刺しゅう移行（複雑さを残さない手順）

| 段階 | やること | やらないこと |
|---|---|---|
| **T0 方針** | グループ方針を One Principal / One US LRD に採択 | 生地だけ先行で口癖を二重化 |
| **T1 契約** | 米契約を買取LRD＋OM＋在庫リスク日本、にamend | 85%条項を生地にコピー |
| **T2 会計** | 仕入／売上の買取仕訳に寄せる | 「売上送金85%」を並行継続 |
| **T3 数値** | 刺しゅうOMをbenchmarkまたは暫定レンジで固定 | カテゴリごとに別性格付け文書 |
| **T4 生地Go** | 同じ契約骨格でquilting schedule追加 | Faireだけ例外モデル |

物理（Faire×3PL）はT0時点で変えなくてよい。

---

## 7. さらに単純化するなら（オプション）— 今は必須にしない

| オプション | 効果 | 代償 |
|---|---|---|
| 生地titleから日本を外し上海→米 | TP段が減る | 日本ownership感が消え、ロイヤルティ設計が必要 → **今の「日本principal」方針と逆** |
| 上海をA（agent）のみ | 一段減 | TeamsのB採用と矛盾、FSRの第一売買の置き方が変わる |
| 米を純agent（titleなし） | 口癖に近い | IOR・3PL実態と衝突 → **非推奨** |

**Simpleの正解は「段を減らす」ではなく「例外を減らす」。**  
段（中国LR）は製造立地のせい。例外（85% vs LRD）を消すのが本丸。

---

## 8. 一枚絵（対外・対内共通メッセージ）

> 米国のCOSMO／LECIEN商品は、日本がprincipal、TANAAKKが限定リスクの買取販売者（IOR）として扱う。  
> 報酬は売上手数料率ではなく、米側の適正な営業利益になるよう仕入価格を調整する。  
> 在庫を米3PLに置く場合も所有はTANAAKK、売れ残り等の経済は日本が支える。  
> 直送も3PLも同じルール。違うのは置き場所だけ。

---

## 9. 批判的自己チェック

1. 刺しゅう85%廃止は米側の見え方・キャッシュに効く — **移行期OM**を明示しないと現場が拒否する。  
2. 「simple」を「上海をなくす」と誤解すると生地FSR・B型と衝突する。  
3. 口癖「売れるまで日本のもの」を残すと、統一モデルが言葉で壊れる。  
4. Distributor OK・Faire別設計、は **物流付則**であり、モデル分岐ではない — 文書を増やしすぎない。  

---

## 10. 一文サマリー

**刺しゅうも生地も、日本principal × 米LRD/IOR ×（必要なときだけ中国LR）に一本化する。売上85%と「売れるまで日本title」は捨て、チャネル差は直送／3PLの物流だけにする。それがいま作れる最もsimpleなビジネスモデルである。**
