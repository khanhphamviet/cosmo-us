# Faire掲載 ＝ 3PL保管チャネル — 生地ビジネス／TPへの含意

**Date:** 2026-09-24  
**Status:** チャネル差分設計（Distributorは現行設計でOK前提）  
**Inputs:** `lecien-us-quilting-fabric-business-tp-design-20260924.md`、FSR原則、Cosmo刺しゅうのFaire×3PL（ShipHero）運用イメージ

---

## 0. 結論

| チャネル | 判定 |
|---|---|
| **Distributor（Checker等）** | 現行設計で **OK**（受注生産・Qingdao→顧客直送・原則米在庫なし） |
| **Faire掲載＋3PL保管** | **別チャネルとして設計が必要。** 法的チェーン（日本principal・上海LR・米LRD）は流用可だが、**在庫・FSR証憑・資金・関税キャッシュ**が変わる |

**一文:** Faireは「米国内に先に在庫を置き、注文後に3PLから出荷する」モデルなので、Distributorの back-to-back 設計をそのまま当てない。**title上はTANAAKKが3PL在庫を持つLRD**とし、滞留・廃棄は日本が契約で吸収。First Saleは「特定問屋名」ではなく **米向け（US 3PL）確定の受注生産ロット**で維持を狙う。

## 1. 何が違うか（Distributor vs Faire/3PL）

| | **Distributor（現行OK）** | **Faire ＋ 3PL** |
|---|---|---|
| 需要のタイミング | 顧客PO → 製造 → 納品 | **先に在庫** → Faire注文 → 3PL出荷 |
| 米国内在庫 | 原則なし | **あり（ShipHero等）** |
| 物理終点 | Qingdao → 顧客（DDP） | Qingdao → **米3PL** → 小売店 |
| LTの見せ方 | 4週受注生産で可 | Faireは**即出荷期待**が強い → 在庫前提 |
| 在庫リスク | ほぼ日本のキャンセル等に限定 | **滞留・値下げ・廃棄・Faire返品**が本格化 |
| 関税キャッシュ | 納品・売上に近い | **販売前に関税支払い**（在庫期間分の運転資本） |
| FSRの証憑 | 特定米向け顧客POと揃えやすい | **「米3PL向け補充」PO**で米向け確定。顧客名は後決めでよいが、**他国転用不可**が必須 |
| 刺しゅうとの類似 | 弱い | **強い**（CosmoはFaire×3PLが既存） |

```
Distributor:  F&A ──► … ──► TANAAKK ──► Checker     （在庫ハブなし）
Faire/3PL:    F&A ──► … ──► TANAAKK ──► 3PL在庫 ──► Faire小売
                              ▲
                         ここで米title＋関税発生
```

## 2. ownership／TP — 推奨（Distributorと思想は同じ）

### 2.1 推奨法形式

| 層 | Faire/3PLでの扱い |
|---|---|
| 日本 | **principal**のまま。3PL在庫の経済リスク（滞留・評価減）を最終負担 |
| 上海 | 変更なし。LCJ指示で **米3PL向け補充ロット**をF&Aへ発注（B型LR） |
| TANAAKK | **IOR＋LRD**。輸入時にtitle取得し、**3PL上の法的所有者**。Faireでは自社（またはmarketplace経由）で販売 |
| 3PL | 保管・出荷の受託者のみ。**titleは持たない** |

**刺しゅう型「売れるまで日本title」を3PLに載せない。**  
輸入IORがTANAAKKなのに倉庫内ownerが日本、は形式／実態不一致になりやすい。代わりに:

- 法的title: **TANAAKK（輸入〜販売）**  
- 経済: **日本が buyback／価格調整／評価減補償**で在庫リスクを吸い上げ → 米は引き続き limited risk（OM目標）

これなら「DistributorでOKとしたLRD思想」と **整合**しつつ、Faire在庫を説明できる。

### 2.2 報酬式

| | Distributor | Faire/3PL |
|---|---|---|
| 米報酬 | OM目標（仮2–3.5%） | **同じOM方針**（チャネル別に経費率だけ違う） |
| 85%/15% | 使わない | **使わない**（在庫ありでも売上15%は関税後に更に厳しい） |
| TP2 | 顧客直送コスト込みで逆算 | **3PL保管料・Pick&Pack・返品・廃却見込**を米経費に入れてTP2を逆算 |
| 日本残余 | 関税・FSR変動 | ＋ **在庫評価減・スロームーブ** |

Provisionalの%自体をチャネルで分ける必要は必ずしもない。**コストとリスクの中身**がチャネルで違う、と文書化する。

## 3. First Sale（Faire在庫でも成立し得る条件）

FSRが求めるのは「特定Checker名」ではなく、第一売買時点で **clearly destined for the United States**。

| やり方 | FSR |
|---|---|
| F&A発注時点で **US 3PL向け・米国外転用禁止・固有PO** | **狙える**（Distributorの顧客PO型より弱いが、日本倉庫グローバル引当より強い） |
| 「とりあえず作り、日米欧どれかに振る」在庫 | **弱い／否認寄り** |
| 3PL在庫をカナダ等へ横流し | **破壊的**（証憑全体が崩れる） |

**運用ゲート（Faire補充用）**

1. LCJが補充数量・SKUを承認（品揃え指示）。  
2. 上海→F&A: POに **US destination / 3PL住所または“for US warehouse stock”**、転用禁止。  
3. 船積・Entry・3PL入庫までUS一貫。  
4. 他市場への振替は原則禁止。やむを得ない場合はFSR前提SKUと分離し、Brokerと事前協議。  
5. Design assistは該当時のみ。

**予算:** Faire在庫分も FSR成功／否認の二本を持つ。否認時の打撃は **販売前在庫にも関税差額が載る**ため、Distributor案件よりキャッシュ痛が大きい。

## 4. オペ・資金・価格

| 論点 | 設計メモ |
|---|---|
| 初回投入量 | LT4週＋Faire回転を見て、**何週分のカバレッジ**かを日本が決める（上海は実行のみ） |
| 運転資本 | 原価＋関税＋運賃を **販売前に固定**。誰がBSに載せるか＝原則TANAAKK、資金支援は日本（貸付／支払条件） |
| 関税 | 入庫時に納付。DDP顧客直送より **早いキャッシュアウト** |
| Faire手数料 | OM計算の「米経費」に必ず入れる（Distributorより厚い可能性） |
| 売価 | Checker $5.92と **同一である必要はない**。Faire卸・MAP・比較価格は別テーブル |
| 返品 | Faire/小売返品の経済は日本へ（契約）。米OMを削らない |
| UFLPA等 | 3PL在庫でもEntryセットは同じ。長期保管でも証憑5年 |

## 5. チャネル併存アーキテクチャ（推奨）

```
                    ┌─ Channel D: Distributor ─► Qingdao → 顧客直送（在庫なし）
  日本 principal ───┤
  上海 LR 発注      └─ Channel F: Faire/3PL ───► Qingdao → 米3PL → Faire出荷（在庫あり）
  TANAAKK LRD/IOR
```

| 共通 | 差分（Channel Fのみ） |
|---|---|
| 日本principal・上海B・米LRD・直送思想（日本倉庫なし） | 米3PL在庫・補充PO・在庫リスク条項・Faire手数料 |
| 刺しゅう15%不使用 | 在庫buyback／評価減の日本負担を契約明記 |
| FSRは米向け分離 | 補充ロット用POテンプレ（顧客名なし・US 3PL宛） |

**やってはいけない併存**

- Faire在庫を日本または上海の「グローバル在庫」と混同する  
- Distributor向け書類とFaire補充書類を流用し、仕向地が曖昧になる  
- Faireだけ刺しゅう85%に戻す

## 6. 刺しゅうFaireとの整合

| | Cosmo刺しゅう（Faire×3PL） | 生地Faire |
|---|---|---|
| 物理 | 米3PL保管・Faire出荷 | **同様でよい** |
| ownership口癖 | 売れるまで日本、など | **使わない**。米title＋日本が経済リスク吸収 |
| 報酬 | net sales 85% | **OM型LRDのまま**（在庫があっても15%に戻さない） |

物理オペは刺しゅうに寄せてよい。**契約・TP・titleの言い方は生地LRDに寄せる。**

## 7. Go / No-Go（Faire在庫を持つ前）

| # | ゲート |
|---|---|
| 1 | 3PL契約上の **baillee（保管者）** とtitleがTANAAKKであることの確認 |
| 2 | 日本–TANAAKK契約に **在庫buyback／評価減／返品** 条項 |
| 3 | FSR用 **US 3PL補充POテンプレ**（転用禁止） |
| 4 | 初回投入SKU・数量・カバレッジ週数のLCJ承認 |
| 5 | 関税＋在庫の運転資本上限（誰が何時払うか） |
| 6 | Faire手数料・返品率を織り込んだ **Channel F用TP2感度** |

未充足なら、Faireは **「掲載のみ・受注後4週（またはFaireのドロップシップ相当）」** に留め、3PL常備は後段、が安全。

## 8. 批判的自己チェック

1. 「DistributorでOK」と「Faireも同じ」は **物流終点が違う** — 同じと言い切ると在庫リスクが契約から落ちる。  
2. US 3PLはFSRと両立し得るが、**転用・越境横流しで一瞬で壊れる**。  
3. 在庫をTANAAKK BSに載せると米のOMが在庫関連費用で振れる — **四半期調整で日本へ戻す**運用が必要。  
4. 少SKU・高回転だけ3PL、長尾はDistributor／受注生産、の **ハイブリッド**が現実的。

## 9. 一文サマリー

**Distributorは現行の直送LRDでよい。Faire掲載で3PL保管するなら、同じ日本principal／上海LR／米LRDを使い、在庫の法的titleはTANAAKK、滞留リスクは日本が契約吸収、FSRはUS 3PL向け受注生産ロットで維持する。刺しゅうの85%式や「売れるまで日本title」は載せない。**
