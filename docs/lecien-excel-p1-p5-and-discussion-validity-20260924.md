## A. これまでの議論はExcelに照らして妥当か

### 総評

**経済・FAR・「15%不可」「日残余」「FSR」の方向は妥当で、Excel P1/P5とも整合する。**  
ただしExcelは **Checker直送・買取LRD・日→米$3.86** 前提なので、議論の到達点（**Consignment+Path B、Faire 3PL、$15/yd→$6.17**）まではExcelがカバーしていない。議論が「間違い」なのではなく、**Excelより契約実態・チャネルに一歩進んでいる**。

| 議論の主張 | Excelとの関係 | 妥当性 |
|---|---|---|
| 日本principal・上海LR・米routine | P1/P5のFARと同じ | **妥当** |
| 上海ROS≈2–3.5% | P1結果≈2.9%、P5=2.5% | **妥当** |
| 米OM≈2–3.5%（15%不可） | P1結果≈2.5%、P5=3%、P4の15%粗利を否定 | **妥当** |
| グループ利益10%を主根拠にしない | P1はまさに10%シェアで上海を決めている | **議論の批判は妥当**（数字は近くても説明順序は議論側が正しい） |
| FSR $2.95、否認~$9.8k、日が吸収 | 感応度シートと一致 | **妥当** |
| 刺しゅうと同じConsignment+SORに寄せる | Excelは買取LRD・$3.86仕入 | **議論が契約正本に近い**（Excelは未更新） |
| Faire 3PLでstorage/pickが乗る | Excel米経費$0.15・倉庫なし | **議論が現実的**（Excelは過小） |
| 小売$15→D$6.17 | Excelは$5.92固定 | **どちらも仮**。$6.17の方が小売式と一致 |

**結論:** 役員・LECIENに対しては「Excel P1の**水準**は使えるが、**契約モデルは署名済みMaster寄せ＋Faire費用を足す**。上海はROSで説明し直せ」が妥当な着地。

## B. P1〜P5 の違い（解説）

共通前提（全パターン）: F&A $2.95、売価 $5.92、関税48.9%、FSR＋assist、Maumee、年間¥50百万換算。  
**違うのは「上海と米国の利益の決め方」だけ**（パイ総額はほぼ同じ、配分が変わる）。

### 一覧

| | 上海の決め方 | 米国の決め方 | 日本 | Excel上の位置づけ |
|---|---|---|---|---|
| **P1** | グループ営業利益の **10%シェア**（結果ROS≈2.9%） | 卸売単価の **5%報酬**（結果OM≈2.5%） | 残余 | **推奨（改定）** |
| **P2** | 売上ROS **4%**（B型上限・上海機能大） | OM **5%**（米機能大） | 残余（薄め） | 機能が厚い場合 |
| **P3** | **A型**（所有なし）cost+ **8%** on 経費 | OM **3%** | 残余（厚め） | 上海エージェント案 |
| **P4** | 日と**同率粗利** | **粗利15%**（刺しゅう同型） | 極薄 | PDF比較・**非推奨** |
| **P5** | 売上ROS **2.5%** | OM **3%** | 残余 | **旧P1**（改定前） |

### 各パターンの読み方

**P1（推奨改定）**  
- ねらい: 米を刺しゅう15%から降ろし、上海に安定黒字、日本に残余。  
- 弱点: 上海を「グループ利益10%」で決める説明がTP文書向きでない（議論どおりROSに言い換え必要）。  
- 米5%: 結果OM≈2.5%でAmount B参考帯に入る。議論のX 4–5%／OM 2–3.5%と同方向。

**P2（上海・米とも厚め）**  
- 上海が仕入主導・米が開拓・与信も重い、という**FARが実際に厚いとき**用。  
- 日本シェアが落ちる（64%）。今の「LCJ指示・上海は窓口」方針とは**FARが合わない**なら採用しない。

**P3（上海A型）**  
- 上海はtitleなし・役務のみ。FSRは「日本がF&Aと直接」前提になり、**今のB型＋F&A→上海$2.95 First Sale設計と矛盾しやすい**。  
- Teams/議論の上海B採用とも不一致。比較用。

**P4（PDF・米粗利15%）**  
- 刺しゅう同型。米がグループ利益の大半を取る（ルシアン側わずか9%）。  
- LCLで上海赤字リスク。Excel自身が移転価格上弱いと比較。**議論・Excelとも不採用で一致。**

**P5（旧P1）**  
- 上海ROS 2.5%・米OM 3%を**最初からTNMM型で固定**。  
- 議論の「FAR＋ROS/OMで説明する」に**いちばん近い**。P1改定は配分結果をルシアン寄りに寄せた版で、方法論はP5の方がきれい。

## D. 一文

**議論はExcelの経済結論（P1/P5）と妥当に整合する。P1〜P5は同じパイの配分レシピで、P1=10%シェア+米5%、P5=ROS2.5%+OM3%、P4=米15%粗利（不適）、P2=両端厚め、P3=上海A型。議論がExcelより進んでいるのは契約形式とFaire/3PLと$15小売。**
