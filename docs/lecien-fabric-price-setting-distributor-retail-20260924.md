# Fabric 価格設定 — Distributor / 米国小売

**Date:** 2026-09-24  
**前提:**  
- 原価（F&A）**$2.95/m**  
- 計画関税 **48.9%**・FSR成功時着地 **≈$4.69/m**（Farmers Branch級）＋バッファ **≈$0.10** → 経済コスト **≈$4.80/m**  
- TANAAKK **X≈4.5%** of Net Sales（改訂TP仮中心帯）  
- **米国小売 = Distributor × 1.33 × 2**（＝ ×**2.66**）  
- 換算: **$/yd = $/m × 0.9144**  
- 市場: Asia mid/high 小売 **≈$11–13.5/yd**、希望含意小売 **$14.4/yd**（既存comps）

**Status:** 推奨レンジ（Broker関税・Faire手数料定義確定前）

## 5. 批判的チェック

1. **小売を$12/ydに合わせにいくと D≈$4.9/m → 着地割れ。** 市場に合わせすぎると死ぬ。  
2. **$5.92は「希望」ではなく、48.9%+X4.5%で残余~$0.85のギリギリ健全ライン。** 推奨中心は一段上の **$6.00**。  
3. 関税が23.9%に下がれば着地≈$3.95 → Dを下げられる／残余が増える。**Broker前に小売を下げ約束しない。**  
4. 式の 1.33×2 は流通仮定。実チャネル（1段卸のみ等）では小売を下げられるが、**ブランドMAPは式どおりの方が説明容易。**  
5. Mode B（中国直送）は送料が配分前控除でも、欠品時LT・顧客体験コストは価格に含めていない。
