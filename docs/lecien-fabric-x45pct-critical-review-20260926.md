# 批判的吟味 — TANAAKK 報酬 **Net Sales × 4.5%**（生地・D=$7.59）

**Date:** 2026-09-26  
**対象:** Category Schedule 仮中心 **X=4.5%**  
**前提価格:** Distributor **$7.59/m**、船便着地 **$4.69**、着地後粗利 **$2.90（GM 38.2%）**  
**スキーム:** Consignment + U.S. Principal／関税・国際物流・Storage＝LCJ／手数料は配分前またはNet控除  
**結論先出し:** **4.5%は「DB前の作業用中心」として条件付きで妥当寄り。確定ALでも最適値でもない。定義を誤ると一瞬で非妥当になる。**

---

## 0. 判定サマリー

| 視点 | 判定 | 一言 |
|---|---|---|
| FAR（routine SOR） | **整合** | 出荷前在庫なし・DEMPEなし → 薄い売上%は方向として正しい |
| 経済（着地後GPの分け前） | **許容〜やや薄め** | 4.5%は GP $2.90 の **≈12%** のみ。LCJに≈88%残る |
| OMクロスチェック | **条件付き合格** | 米オベ≈$0.15/mなら OM≈**2.5%** → 目標帯 2.0–3.5%の中心 |
| vs 刺しゅう15% | **意図的に異なる** | 同率は生地では非妥当（GPの≈39%を米が先取り） |
| vs 独立企業間の「証明」 | **未充足** | 比較会社DBなし。4.5%に統計的根拠はない |
| Net Sales定義依存 | **クリティカル** | 手数料をXから払わせると **即破綻** |
| チャネル | **Distributor向き／Faireは薄い** | FaireでNetが痩せる＋絶対額が小さい |

**総合:** 「4.5%で確定」は言い過ぎ。「4.5%を仮中心にし、OM 2–3.5%で四半期調整」が正確。

## 1. 4.5%は何の数字か（混同しやすい点）

| よくある誤解 | 正しい位置づけ |
|---|---|
| グループ利益の4.5% | **違う**。TANAAKKの **契約報酬率** |
| 着地後粗利率 | **違う**。粗利は≈38%、その一部がX% |
| ALそのもの | **違う**。ALの本丸は文書上 **OM（またはBerry）**。Xは導出 |
| Excel P1「米5%」 | **近いが別物**（Excelは卸売単価比・関税後報酬の定義が違う） |

```
Net Sales E
    │
    ├─ X% ──► TANAAKK（ここから米オベを賄い、残りがOM）
    └─ (100−X)% ──► LCJ ──► −上海 −関税 −物流 −Storage ──► 残余
```

## 2. FARから見た妥当性（支持材料）

TANAAKKの生地FAR（設計どおり）:

- SOR・価格・与信・返金・Faire/Checker窓口・IOR名義  
- **出荷前在庫ownerではない**（Path BまでLCJ）  
- 関税・滞留・FSR・デザインDEMPEは **LCJ**  

→ tested party として **limited-risk distributor / sales agent 的な薄い利益**が自然。  
売上15%級は「厚い販売会社・在庫リスクあり」に見えやすく、**生地FARと不一致**。

**支持:** 4.5%は「薄いroutine」の方向として FAR と矛盾しない。

**弱点:** FARは **率の上限・下限を一意に決めない**。「だから4.5%」までは導けない。3%でも6%でもFAR物語は書ける。

## 3. 経済ハード制約（$7.59で定量）

着地後粗利（グループ原資）**$2.90/m** を100とすると:

| X | TANAAKK $/m | **対着地後GP** | LCJ側に残るGPイメージ |
|---:|---:|---:|---:|
| 3.0% | 0.23 | 7.9% | 厚い |
| **4.5%** | **0.34** | **≈11.8%** | **≈88%** |
| 5.0% | 0.38 | 13.1% | |
| 6.0% | 0.46 | 15.7% | |
| 8.0% | 0.61 | 20.9% | 上限付近 |
| **15%** | **1.14** | **≈39%** | **不適**（関税リスクバッファを米が食う） |

**読み:**

- 4.5%は「米が原資の大半を取る」率ではない → **LCJ principal物語と整合**。  
- 逆に **SORとして薄すぎないか**は、絶対額 **$0.34/m** とオベ次第（次節）。  
- 旧$6帯より Dが上がったので、同じ4.5%でも絶対額は増えた（$6.17×4.5%≈$0.28 → **$0.34**）。経済的には以前より説明しやすい。

## 4. OMクロスチェック（4.5%が「効く」条件）

目標: TANAAKK生地セグメント **OM ≈ 2.0–3.5% of Net Sales**（中心≈2.5%）。

仮に米オベ単価 **$0.15/m**（Excel前提の米国経費級）・Distributorで追加控除なし・Net≈Gross:

```
報酬 $7.59 × 4.5% = $0.342
− オベ $0.15
＝ 利益 $0.192
→ OM ≈ 0.192 / 7.59 ≈ 2.5%
```

→ **定義どおりなら 4.5% は OM中心にほぼ一致。これが「4.5%中心」の最良の根拠。**

### 崩れる条件（批判の核心）

| 条件 | 結果 |
|---|---|
| Faire手数料≈15%を **X%から支払う** | $0.34 − $1.14 ≈ **赤字**。4.5%は完全に非妥当 |
| Pick/pack を Net外でTNKが持ち、かつ重い | OMが2%割れ → Xを上げるか費用をNet控除へ |
| オベが $0.25–0.30/m | 4.5%では OM≈0.5–1% → **低すぎ**（conduit疑義） |
| 関税をTNK経済負担 | 既述のとおり **即破綻**（別問題だがX議論を汚染する） |

**含意:** 4.5%の妥当性は率そのものより **Net Sales定義＋費用負担表**に依存する。Scheduleに「Marketplace・Pick/Packは配分前控除／Storage・関税はLCJ」が書けて初めて4.5%は生きる。

## 5. 刺しゅう15%・Excel・Amount Bとの関係

| 参照 | 生地4.5%への含意 |
|---|---|
| 刺しゅう **15%** | 契約シェルは同型でも **率のコピーは非AL・非経済**。差別の説明は必須（関税構造・GP厚さ） |
| Excel P1「米報酬5%」 | オーダー感は近い。ただしExcelは日→米$3.86仕入物語で、Settlement正本ではない |
| Amount B（繊維IG2の方向感） | OM 数％帯の **クロスチェック**には使える。X=4.5%の直接根拠にはしない |
| 旧TPメモ 4–8%→改訂 3–6% | 4.5%は改訂帯の **中央**。一貫性はある |

## 6. チャネル別の批判

### 6.1 Distributor（Checker）

- 控除少・Net≈$7.59 → 4.5%＝$0.34、OM≈2.5%（オベ$0.15時）→ **いちばんきれい**。  
- 与信・大口営業が重いなら **5–6%** の方がFAR説明しやすい余地あり。

### 6.2 Faire 3PL

- 手数料控除後 Netが痩せる → 同じ4.5%でも絶対額が **$0.29前後**（15%手数料仮）。  
- StorageはLCJだが、米側のCS・返品オペは残る → **Faire比率が高いほど4.5%はタイト**。  
- 対策: (a) Faire建値を$9+/ydへ (b) Xをチャネル別（例: Faire 5–5.5%）(c) オベ実測でOMキャリブレーション。

## 7. 「低すぎ／高すぎ」リスク

| | リスク | 兆候 |
|---|---|---|
| **低すぎ（&lt;3–3.5%）** | 米SORの過少報酬・税務で「利益を日本へ寄せすぎ」 | OM&lt;1.5%、赤字四半期、IOR・与信コストを吸収不能 |
| **4.5%（本件）** | 中央シナリオではOM≈2.5% | Faire偏重・オベ上振れで低すぎ側へ滑る |
| **高すぎ（&gt;6–8%）** | LCJの関税・滞留バッファ不足、principalと不一致 | LCJ残余が薄く価格改定・FSR感度に耐えられない |
| **15%** | 生地では構造不適 | GPの約4割をroutineが先取り |

## 8. まだ言えないこと（知的誠実さ）

1. **比較可能性DB未実施** → 4.5%は IQR の provable point ではない。  
2. **オベ$0.15は仮置き** → 実額が出るまで OM一致は仮説。  
3. Path B＋IORの「routine」説明は Broker／税務で争点になり得る → 率が正しくても **性格付け**が攻撃される。  
4. 月額コンサル$25k等の按分を入れると、売上%だけでは足りない可能性。

## 9. 推奨（吟味後の実務ポジション）

| 項目 | 推奨 |
|---|---|
| 契約の仮中心 | **X=4.5%** を維持してよい（D=$7.59前提） |
| 契約の帯 | **3–6%**（ハード上限8%、15%禁止） |
| 文書化の主指標 | **OM 2.0–3.5%**（中心2.5%）。Xは結果 |
| 必須の定義 | 手数料・pick/pack＝配分前／関税・Storage＝LCJ |
| 見直しトリガー | OMが2四半期連続で帯外、またはFaire売上比率が支配的になったとき |
| 次アクション | 米オベ実測 → X再キャリブ；比較会社検索で provisional を置換 |

## 10. 一文

**4.5% Net Salesは、関税をLCJ・手数料をNet控除としたうえで、TANAAKKのOM≈2.5%を狙う「作業用中心」としては妥当寄り。FARとも矛盾しない。ただしDBなきAL確定値ではなく、手数料定義やオベ上振れで容易に非妥当化し、Faire偏重では薄すぎる。刺しゅう15%との差は説明必須。**
