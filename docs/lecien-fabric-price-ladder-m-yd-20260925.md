# Fabric 価格ラダー — F&A / 上海→LCJ / Distributor（$/m・$/yd）

**Date:** 2026-09-25  
**換算:** `$/yd = $/m × 0.9144`　／　`$/m = $/yd ÷ 0.9144`  
**Distributorロック:** 米国小売 **$15.00/yd** ÷ 2.66 → **$5.64/yd = $6.17/m**

---

## 一覧（ロック／作業用）

| 段階 | 当事者 | **$/m** | **$/yd** | 根拠 |
|---|---|---:|---:|---|
| ① 第三者原価 | F&A → Shanghai | **2.95** | **2.70** | CUP・FSR建値候補 |
| ② グループ内TP | Shanghai → LCJ | **≈3.03**（中心） | **≈2.77** | ROS **2.5%**・経費ゼロ仮: `2.95/(1−0.025)` |
| ②′ 同上（経費込み帯） | Shanghai → LCJ | **≈3.03–3.10** | **≈2.77–2.83** | ROS 2.5–3%＋単位経費。図示の **≈3.09** はこの帯 |
| ③ 米卸 | TANAAKK → Distributor / Faire | **6.17** | **5.64** | 小売$15 ÷ 2.66 |
| （参考）米国小売 MAP | Retail | **16.40** | **15.00** | 固定。式: D × 1.33 × 2 |

```
F&A ──$2.95/m ($2.70/yd)──► Shanghai
```

## 算式メモ

| 項目 | 式 |
|---|---|
| 上海→LCJ（経費ゼロ） | `(F&A) / (1 − ROS)` → ROS 2.5% なら **$3.0256/m ≈ $2.77/yd** |
| 上海→LCJ（経費あり） | `(2.95 + 単位経費) / (1 − ROS)` → 概ね **$3.03–3.10/m** |
| Distributor | `15.00/yd ÷ 2.66 = $5.639/yd` → `÷ 0.9144 = $6.167/m`（表記 **$6.17 / $5.64**） |
| 小売検算 | `$6.167 × 2.66 × 0.9144 = $15.00/yd` |

---

## 注意

1. **$3.09** は「約」の図示値。正式な中心は **ROS 2.5% → ≈$3.03/m**。経費・ROS確定後に Schedule で固定。  
2. Distributor **$6.17/m** は小売$15ロックの逆算。リストをキリよくするなら **$6.15/m** または **$5.65/yd**（小売式は要微調整）。  
3. 関税・着地（≈$4.69/m）はこのラダー外（輸入後コスト）。
