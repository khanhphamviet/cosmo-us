## 2. HTS・関税

| 項目 | 内容 |
|---|---|
| 社内想定 HTS | 5208.52.**4065** |
| 濃飛見積 HTS | 5208.52.**4000**（差異は確認事項） |
| 計画関税スタック | MFN **11.4%** + China §301 **25%** + Forced-labor §301 **12.5%** = **48.9%** |
| 濃飛 DUTY 参考 | **11.4% + 12.5% = 23.9%**（China §301 未計上） |
| 48.9%の性格 | 確定税率ではなく、**23.9%＋当社が25%を足した保守的計画税率** |
| 現時点判断 | 生機・プリントとも中国なら China origin 前提は合理的 → **+25%を計画に入れるのは妥当** |
| 要アクション | 米国 customs broker に、China-origin / 5208.52.40xx で **11.4+25+12.5=48.9%** か、適用 Chapter 99 番号まで書面確認 |

**日本製との違い:** 48.9%は中国原産前提。「出荷港」≠「country of origin」。日本倉庫経由だけでは Japan origin にならない。日本製・Japan origin なら China §301 25%をそのまま載せるロジックは使えない。

## 3. 検討中の商流（2案）

### 案A — 日本を商品商流に入れる
```
F&A（第三者）→ 上海 $2.95 → 日本ルシアン → TANAAKK → Checker等
```
- intercompany TP が **上海→日本** と **日本→TANAAKK** の2段

**選択基準:** 節税だけでなく、**FAR・title・invoice・payment・PO の実態一致**。

## 6. 移転価格：方法論上の最重要修正点（Factとして確定）

現行P1は内部整合しているが、**正式 arm’s-length ではない**。

| 現状 | あるべき順序（TNMM） |
|---|---|
| 上海＝グループ利益の10% → 結果ROS≈2.9% | FAR確定 → comparable → ALレンジ → そのROSになる価格を逆算 → 結果としてシェアが決まる |
| 米国＝売上5%を先に固定 | LRDとして OM を benchmark → 必要な TP を設定（Amount B 1.75–5%は参考・経費率条件に注意） |

日本の残余利益（DEMPE）は、**両端の routine return を控除した後**に残す方が説明力が強い（Coca-Cola / OECD Ch.6 の考え方と整合し得る）。

Excel『妥当性検証』チェックリストは **0/11 未確認**（契約・FSR証憑・assist・文書化等）。

## 7. First Sale Rule（関税評価）— TPとは別問題

### 7.1 原則（確認済み）
F&A→上海の **$2.95** を customs value にするには、その sale 時点で商品が **clearly destined for export to the United States** であること。  
CBP: middleman が manufacturer から購入／購入契約した時点で米向けが明確だったことを **importer が立証**（Nissho Iwai; T.D. 96-87; CBP ICP）。

### 7.2 弱い構造（従来想定）
全世界向け生産 → F&A→上海 → **日本倉庫・global inventory** → 後日 TANAAKK 引当  
→ 第一売買時点で米向け未確定＋転用可能 → **$2.95 FSR は弱い**。

### 7.3 強い構造（検討中）
```
TANAAKK → 上海へ米向け数量発注
→ 上海 → F&Aへ米向け発注
→ F&A → 上海 $2.95
→ Qingdao → U.S. 直送
書類: TANAAKK PO → 上海PO → F&A → U.S.-designated → U.S. shipment が一貫
```
形式だけの変更不可。**title・発注・支払・リスク・物流と一致**させること。

### 7.4 案A vs 案Bと FSR
- **案B（上海→TANAAKK）:** FSR候補＝F&A→上海、次の related sale＝上海→TANAAKK。構造が単純。
- **案A（日本経由）:** FSR否認時にどの sale が customs value になるか含め要設計。倉庫経由は不利。

### 7.5 Design assist
日本 design ≈ **$0.06/m** を FSR value に加算するケースを Excel は想定（関税評価額イメージ **≈$3.01/m**）。  
「日本で design した＝自動 assist」ではない。所有・負担・F&A価格への織り込みを確認。現段階は **provisional**。
