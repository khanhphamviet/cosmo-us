# 添付方針（LCJ consignment × TANAAKK無ownership）— 批判的吟味

**Date:** 2026-09-24  
**Status:** メリデメ批判レビュー（法務・税務・税関の確定意見ではない）  
**対象:** ユーザー添付の2表  
- titleフロー: F&A→上海→LCJ（船上）→U.S. 3PLはLCJ consignment。TANAAKKは原則ownershipなし（米販売／IOR／fulfillment）  
- カテゴリ対照: Principal=LCJ、3PL owner=LCJ、TANAAKK報酬=刺しゅう15%／生地X%、上海は生地のみ  

**対比:** 先行の統一案（TANAAKK=LRD買取・輸入時title）`docs/cosmo-us-unified-simple-business-model-20260924.md`

---

## 0. 添付方針の骨格（要約）

```
Legal title:  F&A → 上海($2.95) → LCJ →（3PLでもLCJ）→ retailer / Checker
TANAAKK:     全段階で原則 title なし。米オペ・IOR・fulfillment
報酬:        刺しゅう 15% ／ 生地 X%（売上連動）
物理:        刺しゅう Japan→U.S. ／ 生地 China→U.S.
```

**狙い（読み取れるメリットの意図）**
- 刺しゅう現行（売れるまで日本・85%/15%）と**口癖・ownershipを揃える**  
- 説明が短い:「全部LCJの在庫、TANAAKKは手足」  
- 生地も同じ型に載せ、差分は上海層と物流起点と報酬率だけ  

---

## 1. メリット（妥当に評価できる点）

| # | メリット | 評価 |
|---|---|---|
| M1 | **グループownershipの物語が一本**（製造後〜売却までLCJ） | 刺しゅうと生地の対外説明・社内教育は容易。Unified LRD案より「誰の在庫か」が直感的 |
| M2 | **TANAAKK BSに在庫を載せない** | 米側の運転資本・評価減がLCJに集中。米OMの振れを在庫で汚しにくい |
| M3 | **F&A→上海 $2.95 bona fide**を明示 | First Saleの第一売買の置き場は明確（生地） |
| M4 | **Channel差をtitleで増やさない**（FaireもCheckerもLCJ→第三者） | 「直送 vs 3PL」で契約型を割らない、という意味ではsimple |
| M5 | **Principal=LCJが両カテゴリ共通** | 先行統一案の「日本principal」思想とは一致 |

---

## 2. デメリット・リスク（批判的本論）

### 2.1 税関・IOR（最重要の綻び候補）

添付は **TANAAKK = IOR** かつ **titleは常にLCJ**。

| 論点 | 問題 |
|---|---|
| IORと所有者の分離 | 実務上は「外国principalの代理人として輸入」で組めるが、**権限委任・誰がdutyを払い誰が価値を申告するか**を契約・Entryで厳密に揃えないと否認・修正申告リスク |
| 課税価格 | 米国内に「TANAAKKへの売却」が無い。Entryの建値は、(a) FSRでF&A→上海 $2.95、(b) 上海→LCJの関連者価格、(c) 将来の米販売価格の推定、のどれで戦うかをBrokerと固定する必要あり。**表だけでは不足** |
| 関連者 | LCJ–上海–TANAAKKの関係で、IORがグループ米法人だと **related-party valuation** の説明負担は消えない（titleを米に移さないことで軽減されるわけではない） |
| Checker直送 | 「China→Checker」なのに title は LCJ→Checker。IORがCheckerかTANAAKKかで話が変わる。**⑦行は①–⑥と物流が別物**なのに同じownership物語に無理に載せている |

**結論:** 「IORなのにownershipなし」は**口頭ではsimple、実装では最難所**。ここを曖昧にしたまま進めると、unified LRD案より税関リスクが高い。

### 2.2 米国PE・連邦・州税

| 論点 | 問題 |
|---|---|
| 在庫PE | **LCJ名義の商品がNJ等の3PLに常駐** → 州の経済ネクサス／在庫による課税関係がLCJに直接付きやすい |
| 代理人PE | Faire/Distributor売上が **LCJ→顧客**で、TANAAKKが常習的に契約締結・交渉するなら、連邦の **dependent agent PE** 議論が起きやすい（名称がoperatorでも実態で見られる） |
| 売上税 | 売主がLCJなら、Marketplace（Faire）以外のDistributor売上は **LCJのsales tax登録・徴収**設計が必要。TANAAKK売主のLRD案より日本本体側のコンプラが重い |
| 移転価格 | 米に売却が無いので「日本→米のTP2」は消えるが、代わりに **役務（販売・IOR・fulfillment）の対価15%/X%** のAL性を説明する必要。役務なのに在庫・与信・返品を実質見ていると、また性格付けがずれる |

**結論:** ownershipを日本に残すほど、**日本が米国で「自分で売っている」色が濃くなる**。simpleな所有図と引き換えに、PE・州税の正面突破が必要。

### 2.3 報酬15% / X%（生地で特に危険）

| 論点 | 問題 |
|---|---|
| 刺しゅう15% | 厚マージン前提ならオペ上は継続しやすい。ただし上のPE・性格付けとセット |
| 生地 X% | 関税≈48.9%予算下では、**売上連動%は総粗利を容易に食う**（既存レビューどおり）。Xを小さくしても「刺しゅうと同型」の安心感は薄い |
| Duty負担 | 販売前に関税が出る。owner=LCJなら経済はLCJ負担が自然。TANAAKKが立替→精算でも、**%報酬の分母（net sales）に関税をどう扱うか**で現場が揉めやすい |
| 「operatorなのに%」 | 純粋な役務なら cost+ や固定＋薄い%の方が説明しやすい。在庫なし・与信なしと言いながら15%は、**実態がdistributorに近いと税務・税関双方で突かれる** |

### 2.4 First Sale・consignmentの相性

| 論点 | 評価 |
|---|---|
| F&A→上海 $2.95 | 米向け分離ができればFSR候補として有効（表②は良い） |
| その後LCJが米で長期在庫 | 「clearly destined for US」自体は3PL向けでも維持し得る。ただし **Entry建値がFSR成功しても、その後の関連者・再販をどう見るか**はBroker案件 |
| 否認時 | 関連者建値（上海→LCJ）に落ちやすい。LCJ consignmentのまま米販売までtitleが移らないので、**否認インパクトの吸収先は最初からLCJ**（ここは意図と一致） |

### 2.5 「simple」かの再判定

| 見えるsimple | 隠れたcomplex |
|---|---|
| 所有表が1列（ずっとLCJ） | IOR委任、Entry建値、PE、州税、役務TP、Faire規約上の売主名義 |
| 刺しゅうと同じ口癖 | 生地は上海＋中国原点＋高関税で、**同じ口癖のまま数字だけX%は破綻しやすい** |
| TANAAKK無在庫 | 3PL契約の寄託者＝LCJ、保険、廃棄、荷主責任の英文契約が増える |

**判定:** ビジネスストーリーとしてはsimple。**税関・税・契約の実装としては、LRD買取案より単純とは言い切れない。** 「例外を減らす」方向（両カテゴリLCJ inventory）には効くが、「リスクを減らす」方向には必ずしも効かない。

## 3. 先行LRD案との対照

| | **添付: LCJ consignment + %** | **先行: TANAAKK LRD買取 + OM** |
|---|---|---|
| 3PL title | LCJ | TANAAKK |
| TANAAKK | operator / 原則無ownership / IOR | LRD / 輸入時title / IOR |
| 刺しゅうとの見た目 | **最も近い** | 契約・口癖の変更が必要 |
| 米在庫BS | LCJ | TANAAKK（経済は日本へ転嫁可） |
| PE・州税 | **LCJ正面** | 主にTANAAKK（日本は役務・売買のTP） |
| IORとtitle | **分離（難所）** | **一致（説明しやすい）** |
| 生地報酬 | X%（関税下で脆弱） | OM（仕入TPで調整） |
| FSR | 第一売買は同様に狙える | 同様 |
| 運用変更 | 刺しゅうは現状維持に近い | 刺しゅうの85%廃止・仕訳変更 |

## 4. 条件付きで「添付を採る」なら必須のガードレール

添付を採択するなら、少なくとも次を**採択条件**にする（未充足なら採るべきでない）:

1. **Broker書面:** consignment＋TANAAKK IORで、申告者・課税価格（FSRの可否）・関連者開示の型  
2. **IOR委任契約:** 権限・duty立替・罰則・記録保管の帰属  
3. **PE・州税メモ（米税理士）:** LCJ在庫＋LCJ売主前提の登録・PE緩和（代理人の権限制限、契約名義の設計）  
4. **3PL寄託契約の寄託者=LCJ**（TANAAKKは通知先／オペ指示者に過ぎないことの整理）  
5. **生地のX%:** 売上%ではなく、**(a) 薄いOM相当の役務料**または **(b) 関税控除後GP連動**に最初から定義。刺しゅう15%のコピペ禁止  
6. **Faire:** プラットフォーム上の売主名義・支払先がLCJかTANAAKKか。表の「LCJ→retailer」と口座実態を一致  
7. **Checker:** IORとDDP当事者を⑦専用に書き分け（③–⑤の3PL物語と混線させない）

## 5. 総合判定

| 観点 | 判定 |
|---|---|
| 刺しゅうとの整合・社内の分かりやすさ | **添付が優位** |
| 税関（IOR×title）・PE・州税の実装リスク | **添付が劣位（重い）** |
| 生地の利益構造（高関税） | **%報酬は劣位。OM/仕入調整の方が安全** |
| 「できるだけsimple」 | **図は添付がsimple。法令実務はLRDの方が単純になりやすい** |

**推奨スタンス（批判的結論）**

- **「所有の物語を刺しゅうに揃えたい」**のが最優先なら、添付は候補。ただし **IOR無titleとLCJ売主PEを、Broker＋米税理士で通すまでGoしない**。生地報酬は15%同型にしない。  
- **「税関・税・契約の事故確率を下げつつ一本化」**が最優先なら、**先行のTANAAKK LRD（輸入時title・OM）の方がまだマシ**。刺しゅうは口癖を「principalはLCJ」に更新するコストを払う。  
- 中間の偽simple（**表はconsignment、実態はTANAAKKが売主・与信・在庫判断**）は**両方の最悪**なので明確に除外。

## 6. 一文サマリー

**添付方針はownership説明を最も単純化するが、IORと所有者の分離・LCJの米PE/州税・生地の売上%報酬という三つの実装リスクを抱える。simpleなのは図であり、オペ全体ではない。採るならガードレール必須、生地X%の刺しゅうコピーは不可。**
