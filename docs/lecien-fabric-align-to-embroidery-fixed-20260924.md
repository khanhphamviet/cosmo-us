# 刺しゅう方針固定前提 — fabricをどこまで近づけられるか

**Date:** 2026-09-24  
**Status:** 可否判断（刺しゅう現行は変更しない前提）  
**刺しゅう固定（現行）:** LCJが売れるまでowner／売却時にtitle移転／net salesの85%を日本へ（米≈15%）／TANAAKKはU.S. operator（原則ownershipなし）／物理は概ね Japan→U.S.  
**参照:** 添付consignment表、`lecien-us-consignment-model-critical-review-20260924.md`、統一LRD案

---

## 0. 結論

**可能。ただし「全部コピー」は不可。「ownership物語＋米オペの型」まで近づけるのが上限で、調達・関税・報酬率は生地固有のまま残る。**

| 寄せ方 | 可否 |
|---|---|
| A. 刺しゅうと同じ口癖・同じtitle図（売れるまでLCJ、TANAAKK無ownership） | **可能（添付方針）** — 実装ガードレール必須 |
| B. 刺しゅうと同じ報酬式（売上15%固定） | **非推奨〜不可に近い** — 関税48.9%下で利益構造が壊れる。近づけるなら **薄いX%または役務料** |
| C. 刺しゅうと同じ調達（上海なし・日本出荷） | **不可** — 生地はF&A中国・Shanghai B・China→U.S.が前提 |
| D. 刺しゅうを動かして生地に合わせる | **今回スコープ外**（刺しゅう固定） |

**実務おすすめ:** 刺しゅう固定のまま、生地は **Aを採って近づける**（LCJ consignment × TANAAKK operator/IOR）。報酬だけは **同型の「%」でも中身はX≠15**。Shanghai層とFSRは生地専用スケジュールとして明示する。

## 2. 「近づける」具体案（刺しゅう固定のまま）

### 2.1 採用する共通シェル（刺しゅう互換）

1. 製造後の最終group owner = **LCJ**  
2. U.S. 3PL = **LCJ consignment inventory**  
3. TANAAKK = **ownershipなし**の U.S. operator（販売・IOR・fulfillment）  
4. 売却 = **LCJ → retailer / distributor**  
5. 対外説明: 「米国在庫はLCJ。TANAAKKは米オペ」

→ 添付表の骨格そのもの。刺しゅう方針を変えずに生地を載せる形。

### 2.2 生地だけの付則（ここを削ると寄せ失敗 or 法務事故）

| 付則 | 理由 |
|---|---|
| 上海B・$2.95 bona fide | 中国調達とFSR |
| 米向け分離の受注生産PO | FSR・転用禁止 |
| IOR委任（LCJ→TANAAKK） | titleなきIORを契約化 |
| 報酬X%の定義 | 関税・返品・Faire手数料控除後か等。**15%禁止** |
| 関税・滞留の経済=LCJ | ownerと一致させる |
| Checker直送のIOR書き分け | 3PL経路と混線させない |

### 2.3 報酬の「近づけ方」

| 案 | 内容 | 刺しゅうとの距離 |
|---|---|---|
| **型合わせ・率分離（推奨）** | どちらも「net sales連動のオペ報酬」。刺しゅう15%、生地は例: 3–7%または関税後GPの一定率 | 説明は近い。数字は違うと明言 |
| 率まで合わせ15% | 生地に15% | **経済破綻。不可** |
| 生地だけOM/仕入TP | LRD型 | 刺しゅうと型が再び割れる（寄せ失敗） |

刺しゅうを固定する以上、**生地をLRD買取にすると「型」がまた二つになる**。寄せるなら添付シェル＋X%が本線。

## 3. 近づけた場合に残るリスク（直視）

寄せる＝添付方針を生地に採用する、なので批判レビューの論点はそのまま残る:

1. **IOR≠owner**（Broker必須）  
2. **LCJの米在庫PE・州税**（刺しゅうが既に同じ型なら、生地追加は「在庫量・関税キャッシュ」が増えるだけ、という整理も可 — ただし刺しゅう側も未検証なら一緒に触る必要）  
3. **FSRと長期3PL**の証憑  
4. **X%の合意**（ルシアン・TANAAKK）  

**逆に楽になる点:** 社内・対外の「なぜ生地だけ買取LRD？」が消える。刺しゅう固定方針との政治的・説明的衝突が最小。

| 問い | 答え |

| Goの条件 | Broker＋IOR委任＋生地X%定義＋（望ましく）米税務の在庫/売主メモ |

## 5. 一文サマリー

**刺しゅう方針を固定したままなら、生地は「LCJが売れるまでowner・TANAAKKは無ownershipオペ・報酬は%型」まで寄せられる。上海・中国直送・FSR・報酬率だけは生地固有として残す。15%同一は不可。寄せる＝実質添付consignment採択であり、IOR/PEのガードレールは必須。**
